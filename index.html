Verificación automática de soldaduras en una línea de producción

Pipeline de deep learning en dos etapas desarrollado para IPTE Spain (Reus): un detector RT-DETR localiza cada soldadura y una U-Net la segmenta píxel a píxel, generando un mapa de calor fácil de interpretar para el operario. Alcanza un coeficiente Dice de 0,92 en tiempo real y, gracias a un flujo con validación humana (human-in-the-loop), se adapta a un nuevo tipo de soldadura con unas 50 imágenes etiquetadas.

  • RT-DETR
  • U-Net
  • PyTorch
  • Transfer learning
  • Human-in-the-loop
3

Recuento de piezas en imágenes térmicas

Sistema de visión por computador clásica que cuenta las piezas completas de una línea de termosellado a partir de imágenes de una cámara termográfica. El aplanado del fondo, la detección de líneas y círculos mediante la transformada de Hough y el filtrado por bordes conservan solo las piezas totalmente visibles; los parámetros se ajustaron automáticamente y el recuento fue correcto en las 7 imágenes de muestra.

  • OpenCV
  • Transformada de Hough
  • Termografía
  • Python

Redacción de artículos con agentes de CrewAI

Un equipo de tres agentes LLM (investigador, redactor y editor) convierte un tema en un artículo listo para publicar. El investigador prepara un esquema que aprueba una persona, el redactor escribe un borrador de más de 800 palabras y el editor revisa la claridad, la precisión y la gramática. La memoria compartida funciona con embeddings locales de Ollama.

  • CrewAI
  • Agentes LLM
  • Ollama
  • Human-in-the-loop
3

Detección de grietas en superficies de hormigón

Modelo de deep learning que detecta grietas píxel a píxel en fotos de hormigón y asfalto, para la inspección automatizada de edificios e infraestructuras. Se basa en la arquitectura DeepCrack (una red VGG-16 con salidas laterales a varias escalas), entrenada en PyTorch con 300 imágenes anotadas; en 237 imágenes de prueba nuevas alcanza un F1 de 0,71, aunque las grietas miden solo unos pocos píxeles de ancho.

  • PyTorch
  • Segmentación semántica
  • VGG-16
  • Inspección de infraestructuras

Planificación de misiones con sistemas multiagente

Arquitectura de un sistema CrewAI que planifica una misión de exploración en Marte con rovers, drones y satélites. Seis equipos de agentes especializados se reparten el trabajo: uno prepara los datos de la misión, cuatro planifican las rutas de cada tipo de vehículo y otro lo integra todo en un único plan que respeta las restricciones de energía, tiempo y terreno. Diseñado en un equipo de cinco personas.

  • CrewAI
  • Sistemas multiagente
  • Planificación
  • Análisis de grafos

Estadísticas sobre datos cifrados

Aplicación web que permite a un servidor no fiable calcular estadísticas sobre datos sensibles sin descifrarlos nunca. Implementa en Python el homomorfismo de privacidad de Domingo-Ferrer (claves de 200 dígitos, cifrado probabilístico) y calcula medias, covarianza y una regresión sobre un conjunto de datos médicos cifrado; solo el propietario de los datos puede leer los resultados. Desarrollado en un equipo de tres personas.

  • Python
  • Cifrado homomórfico
  • Flask
  • Privacidad de datos
