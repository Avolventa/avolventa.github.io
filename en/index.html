Automated Weld Verification on a Production Line

A two-stage deep learning pipeline built for IPTE Spain (Reus): an RT-DETR detector finds each weld, then a U-Net segments it pixel by pixel and produces a heatmap the operator can read. It reaches a Dice score of 0.92 in real time, and a human-in-the-loop workflow adapts it to a new weld type with about 50 labelled images.

  • RT-DETR
  • U-Net
  • PyTorch
  • Transfer learning
  • Human-in-the-loop

Counting Parts in Thermal Images

A classical computer vision system that counts complete parts on a heat-sealing line from thermographic camera images. Background flattening, Hough line and circle detection and edge filtering keep only fully visible parts; the parameters were tuned automatically and the count was correct on all 7 sample images.

  • OpenCV
  • Hough transform
  • Thermography
  • Python

Multi-Agent Article Writing with CrewAI

A team of three LLM agents (researcher, writer and editor) turns a topic into a publication-ready article. The researcher drafts an outline that a human approves, the writer produces a draft of 800+ words and the editor checks clarity, accuracy and grammar. Shared memory runs on local Ollama embeddings.

  • CrewAI
  • LLM agents
  • Ollama
  • Human-in-the-loop

Crack Detection on Concrete Surfaces

A deep learning model that finds cracks pixel by pixel in photos of concrete and asphalt, for automated inspection of buildings and infrastructure. It is based on the DeepCrack architecture (a VGG-16 network with multi-scale side outputs), trained in PyTorch on 300 annotated images; on 237 unseen test images it reaches an F1 score of 0.71, even though cracks are only a few pixels wide.

  • PyTorch
  • Semantic segmentation
  • VGG-16
  • Infrastructure inspection

Multi-Agent Mission Planning

Architecture for a CrewAI system that plans a Mars exploration mission for rovers, drones and satellites. Six crews of specialised agents share the work: one prepares the mission data, four plan the routes for each vehicle type, and one merges everything into a single plan that respects energy, time and terrain constraints. Designed in a team of five.

  • CrewAI
  • Multi-agent systems
  • Planning
  • Graph analysis

Statistics on Encrypted Data

A web app that lets an untrusted server calculate statistics on sensitive data without ever decrypting it. It implements the Domingo-Ferrer privacy homomorphism in Python (200-digit keys, probabilistic encryption) and computes means, covariance and a regression on an encrypted medical dataset; only the data owner can read the results. Developed in a team of three.

  • Python
  • Homomorphic encryption
  • Flask
  • Data privacy
